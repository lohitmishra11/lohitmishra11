### `whoami`

I like teaching machines to **read, retrieve, and reason**. My work lives at the intersection of agentic AI, retrieval-augmented systems, and the quiet art of automating things nobody wants to do by hand. I've built regulatory-intelligence platforms that read thousands of records so people don't have to, trained models that forecast timelines instead of guessing at them, and RAG pipelines that turn dense, unreadable text into plain answers. I care less about writing more code and more about writing code that disappears — the kind that just runs, quietly, in the background, doing the boring part so someone else doesn't have to.
